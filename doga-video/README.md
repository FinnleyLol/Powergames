# Doğa – die Natur auf Türkisch 🇩🇪 → 🇹🇷

Lernvideo (1080p, ca. 8 Minuten): 40 Nomen aus der Natur mit **türkischer Aussprache**, dazu zwei Bonus-Teile:
**Gegensätze mit Adjektiven** (*büyük ağaç – küçük çiçek*) und **kleine Sätze in der Natur**
(*Ormanda yürüyorum.*), die Wörter aus den anderen Videos wiederholen.

▶️ **Video:** [`output/doga_natur_deutsch_tuerkisch.mp4`](output/doga_natur_deutsch_tuerkisch.mp4)

**Zur Betonung:** Die rote bzw. fette Silbe stammt aus der Lautschrift der Stimme. Bei *deniz*, *yıldız* und *ağaç*
hat die Stimme falsch betont oder Silben verschluckt. Dort spricht sie jetzt aus korrigierter Lautschrift:
de·**niz**, yıl·**dız**, aa·**atsch**. Bei *tohum* und *şelale* klang die Korrektur schlechter. Dort ist keine
Silbe markiert, und die Stimme betont etwas zu früh (richtig: to·**hum**, sche·la·**le**).

**Aussprache-Check:** 86 von 101 türkischen Aufnahmen wurden von Whisper exakt erkannt. Die meisten
Abweichungen sind richtige Aussprache, die nur anders geschrieben wird: *dağ* → „da“ (das ğ macht das a lang),
*plaj* → „plaş“ (am Wortende stimmlos), *sığ dere* → „Sıdere“. *doğa* und *tepe* hört die Erkennung als
Einzelwort manchmal falsch, im Satz aber sicher (*Doğa çok güzel.* 8 von 8, *Tepe çok yüksek.* 6 von 8).

## Video selbst neu erzeugen

Voraussetzungen: Python 3.10+, `ffmpeg` und die Cairo-Bibliothek (für die SVG-Bilder).
Die Technik liegt in [`../lernvideo/`](../lernvideo/): `engine.py` (Stimmen, Grafik, Rendern) und
`nouns.py` (Bausteine für Wortkarten-Videos). Hier stehen nur Inhalte, Bonus-Szene und Bilder.

```bash
pip install -r requirements.txt          # im Hauptordner des Repositorys
cd doga-video
python make_video.py                      # erzeugt output/doga_natur_deutsch_tuerkisch.mp4
python make_video.py --preview            # nur Standbilder nach build/preview/
pip install sherpa-onnx
python make_video.py --verify --takes 20  # Aussprache per Whisper prüfen, beste Aufnahme je Wort wählen
```
