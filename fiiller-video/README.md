# Fiiller – die wichtigsten Verben auf Türkisch 🇩🇪 → 🇹🇷

Lernvideo (1080p, ca. 10 Minuten) für Anfänger: 20 wichtige türkische Verben mit **türkischer Aussprache**,
den ersten Grammatik-Regeln und Beispielsätzen mit Wörtern, die du schon kennst (Essen, Tiere, Orte).

▶️ **Video:** [`output/fiiller_verben_deutsch_tuerkisch.mp4`](output/fiiller_verben_deutsch_tuerkisch.mp4)

## So ist das Video aufgebaut

| Teil | Inhalt |
|---|---|
| Merhaba | *fiil* = das Verb, *fiiller* = die Verben |
| Schritt 1 | Grundform auf **-mek / -mak** (wie -ler / -lar). Stamm = Befehl: *Gel!* = Komm! |
| Schritt 2 | Ich-Form: **Stamm + iyorum** → *geliyorum* = ich komme |
| Schritt 3 | Wer? *geliyor**um*** (ich), *geliyor**sun*** (du), *geliyor* (er/sie/es) |
| Schritt 4 | Satzbau: **das Verb steht am Ende** → *(Ben) elma yiyorum* = „Ich Apfel esse.“ |
| Bölüm 1–4 | 20 Verbkarten: Grundform (normal + langsam) → ich-Form → Beispielsatz, jeweils mit Pause zum Nachsprechen |
| Bonus | Verneinung mit **-m-**: *biliyorum* → *bil**m**iyorum* (ich weiß nicht) |
| Super-Sätze | *Anlamıyorum.* · *Bilmiyorum.* · *Biraz Türkçe konuşuyorum.* · *İstemiyorum, teşekkürler.* |
| Quiz | 10 Verben: deutsches Verb, 3-2-1, dann Grundform + ich-Form |
| Übersicht | Alle 20 Verben auf einer Seite (zum Anhalten und Abfotografieren) |

Die MP4-Datei hat Kapitelmarken, so kannst du in Playern wie VLC direkt zu einem Teil springen.

## Die Regeln auf einen Blick

| Regel | Beispiel |
|---|---|
| Grundform: letzter Vokal e, i, ö, ü → **-mek**; a, ı, o, u → **-mak** | gel**mek** (kommen), al**mak** (nehmen) |
| Stamm = Grundform ohne -mek/-mak = **Befehl** | *Gel!* = Komm! · *Bak!* = Schau! |
| Ich-Form: Stamm + **iyorum** (das i passt sich an: i · ı · u · ü) | gel**iyorum**, al**ıyorum**, konuş**uyorum**, gör**üyorum** |
| Endet der Stamm auf einen Vokal, fällt er weg | anla → anl**ıyorum**, iste → ist**iyorum** |
| Ausnahmen in diesem Video | git → **gid**iyorum (t → d), ye → **yi**yorum |
| -yor**um** = ich · -yor**sun** = du · -yor = er/sie/es | geliyorum · geliyorsun · geliyor |
| Das Verb steht **am Ende**, *ben* (ich) lässt man meist weg | *Elma yiyorum.* = Ich esse einen Apfel. |
| Verneinung: Stamm + **m** + iyorum | bil**m**iyorum (ich weiß nicht), anla**m**ıyorum (ich verstehe nicht) |
| Betonung: Grundform auf der letzten Silbe, ich-Form auf der Silbe vor -yor | gel·**mek**, ge·**li**·yo·rum |

## Alle 20 Verben

### 1. Günlük hayat – Alltag

| Deutsch | Grundform | Aussprache | ich-Form | Beispielsatz |
|---|---|---|---|---|
| essen | **yemek** | je · **mek** | yiyorum (ich esse) | *Elma yiyorum.* – Ich esse einen Apfel. |
| trinken | **içmek** | itsch · **mek** | içiyorum (ich trinke) | *Su içiyorum.* – Ich trinke Wasser. |
| schlafen | **uyumak** | u · ju · **mak** | uyuyorum (ich schlafe) | *Kedi uyuyor.* – Die Katze schläft. |
| arbeiten | **çalışmak** | tscha · lısch · **mak** | çalışıyorum (ich arbeite) | *Çok çalışıyorum.* – Ich arbeite viel. |
| machen | **yapmak** | jap · **mak** | yapıyorum (ich mache) | *Ne yapıyorsun?* – Was machst du? |

### 2. Hareket – Bewegung

| Deutsch | Grundform | Aussprache | ich-Form | Beispielsatz |
|---|---|---|---|---|
| gehen / fahren | **gitmek** | git · **mek** | gidiyorum (ich gehe) | *Eve gidiyorum.* – Ich gehe nach Hause. |
| kommen | **gelmek** | gel · **mek** | geliyorum (ich komme) | *Köpek geliyor.* – Der Hund kommt. |
| zu Fuß gehen / spazieren | **yürümek** | jü · rü · **mek** | yürüyorum (ich gehe zu Fuß) | *Parkta yürüyorum.* – Ich spaziere im Park. |
| rennen | **koşmak** | kosch · **mak** | koşuyorum (ich renne) | *At koşuyor.* – Das Pferd rennt. |
| sitzen / wohnen | **oturmak** | o · tur · **mak** | oturuyorum (ich sitze) | *Burada oturuyorum.* – Ich sitze (oder: wohne) hier. |

### 3. Duyular ve dil – Sinne & Sprache

| Deutsch | Grundform | Aussprache | ich-Form | Beispielsatz |
|---|---|---|---|---|
| sehen | **görmek** | gör · **mek** | görüyorum (ich sehe) | *Bir kuş görüyorum.* – Ich sehe einen Vogel. |
| schauen | **bakmak** | bak · **mak** | bakıyorum (ich schaue) | *Bak, bir kedi!* – Schau, eine Katze! |
| zuhören | **dinlemek** | din · le · **mek** | dinliyorum (ich höre zu) | *Müzik dinliyorum.* – Ich höre Musik. |
| sprechen | **konuşmak** | ko · nusch · **mak** | konuşuyorum (ich spreche) | *Telefonda konuşuyorum.* – Ich telefoniere. |
| verstehen | **anlamak** | an · la · **mak** | anlıyorum (ich verstehe) | *Seni anlıyorum.* – Ich verstehe dich. |

### 4. Diğer önemli fiiller – Weitere wichtige Verben

| Deutsch | Grundform | Aussprache | ich-Form | Beispielsatz |
|---|---|---|---|---|
| wollen / möchten | **istemek** | is · te · **mek** | istiyorum (ich möchte) | *Bir çay istiyorum.* – Ich möchte einen Tee. |
| lieben / mögen | **sevmek** | sew · **mek** | seviyorum (ich mag) | *Köpekleri seviyorum.* – Ich mag Hunde. |
| wissen | **bilmek** | bil · **mek** | biliyorum (ich weiß) | *Evet, biliyorum.* – Ja, ich weiß. |
| lernen | **öğrenmek** | öö · ren · **mek** | öğreniyorum (ich lerne) | *Her gün Türkçe öğreniyorum.* – Ich lerne jeden Tag Türkisch. |
| nehmen / kaufen | **almak** | al · **mak** | alıyorum (ich kaufe) | *Ekmek alıyorum.* – Ich kaufe Brot. |

**Neue kleine Wörter aus den Beispielsätzen:** *su* = Wasser · *çok* = viel, sehr · *ne* = was · *eve* = nach Hause ·
*burada* = hier · *bir* = ein/eine · *seni* = dich · *evet* = ja · *hayır* = nein · *her gün* = jeden Tag ·
*biraz* = ein bisschen · *teşekkürler* = danke

## Video selbst neu erzeugen

Voraussetzungen: Python 3.10+, `ffmpeg` und die Cairo-Bibliothek (für die SVG-Bilder).
Die gemeinsame Technik liegt in [`../lernvideo/engine.py`](../lernvideo/engine.py); hier stehen nur Inhalte und Szenen.

```bash
pip install -r requirements.txt          # im Hauptordner des Repositorys
cd fiiller-video
python make_video.py                      # erzeugt output/fiiller_verben_deutsch_tuerkisch.mp4
python make_video.py --preview            # nur Standbilder nach build/preview/
pip install sherpa-onnx
python make_video.py --verify --takes 10  # Aussprache per Whisper prüfen, beste Aufnahme je Satz wählen
```

Verben, Sätze, Tipps und Quizfragen stehen oben in `make_video.py` (`CHAPTERS`, `PHRASES`, `QUIZ` …).
