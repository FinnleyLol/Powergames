# Evde – Einrichtung auf Türkisch 🇩🇪 → 🇹🇷

Lernvideo (1080p, ca. 7 Minuten): 25 Wörter für Möbel und Dinge in der Wohnung mit **türkischer Aussprache**,
dazu drei kurze Bonus-Teile: **wo?** (*masada* = auf dem Tisch), **auf / unter / neben** (*Kedi masanın altında.*)
und **es gibt / es gibt nicht** (*var / yok*).

▶️ **Video:** [`output/evde_einrichtung_deutsch_tuerkisch.mp4`](output/evde_einrichtung_deutsch_tuerkisch.mp4)

## Wortliste

Die Betonung stammt direkt aus der Lautschrift der Stimme, damit Hinweis und Ton zusammenpassen.
Achtung bei *masa* und *çekmece*: Diese Lehnwörter werden **vorn** betont.

### 1. Oturma odası – Wohnzimmer

| Deutsch | Türkisch | Aussprache (betonte Silbe **fett**) | Tipp |
|---|---|---|---|
| der Tisch | **masa** | **ma** · sa | Betonung hier auf der ersten Silbe! |
| der Stuhl | **sandalye** | san · dal · **je** | y = „j“ |
| das Sofa | **kanepe** | ka · ne · **pe** | Wie das deutsche „Kanapee“! |
| der Sessel | **koltuk** | kol · **tuk** | koltuk heißt auch: Sitz (im Bus, im Kino) |
| der Teppich | **halı** | ha · **lı** | ı = dumpfes i · Türk halısı = türkischer Teppich |
| die Lampe | **lamba** | lam · **ba** |  |
| der Vorhang | **perde** | per · **de** | perde heißt auch: der Vorhang im Theater |
| das Bücherregal | **kitaplık** | ki · tap · **lık** | kitap = das Buch → kitaplık |
| der Fernseher | **televizyon** | te · le · wis · **jon** | v ≈ w · z = weiches s |
| das Bild | **tablo** | tab · **lo** | tablo heißt auch: die Tabelle |

### 2. Yatak odası – Schlafzimmer

| Deutsch | Türkisch | Aussprache (betonte Silbe **fett**) | Tipp |
|---|---|---|---|
| das Bett | **yatak** | ja · **tak** | y = „j“ |
| das Kissen | **yastık** | jas · **tık** | ı = dumpfes i |
| die Decke | **battaniye** | bat · ta · ni · **je** | tt: das t kurz halten |
| der Schrank | **dolap** | do · **lap** | auch: der Küchenschrank |
| der Spiegel | **ayna** | ai · **na** | ay klingt wie „ei“ |
| die Schublade | **çekmece** | **tschek** · me · dsche | ç = „tsch“ · c = „dsch“ · Betonung vorn! |
| die Uhr | **saat** | sa · **at** | saat heißt auch: die Stunde |

### 3. Mutfak ve banyo – Küche & Bad

| Deutsch | Türkisch | Aussprache (betonte Silbe **fett**) | Tipp |
|---|---|---|---|
| der Kühlschrank | **buzdolabı** | bus · do · la · **bı** | wörtlich: Eis-Schrank (buz + dolap) |
| der Backofen | **fırın** | fı · **rın** | fırın heißt auch: die Bäckerei |
| der Herd | **ocak** | o · **dschak** | c = „dsch“ · Ocak heißt auch: Januar! |
| die Waschmaschine | **çamaşır makinesi** | tscha · ma · **schır**   ma · ki · ne · si | çamaşır = die Wäsche · makine = die Maschine |
| das Waschbecken | **lavabo** | la · wa · **bo** | v ≈ w |
| die Badewanne | **küvet** | kü · **wet** | v ≈ w |
| die Dusche | **duş** | **dusch** | ş = „sch“ · u wie in „Dusche“, nicht ö! |
| die Toilette | **tuvalet** | tu · wa · **let** | fast wie „Toilette“ |

**Zur Aussprache:** *duş* spricht die Stimme mit leicht langem u („duuş“). Sonst klang es wie „döş“.
Richtig ist ein kurzes, klares **u** wie in „Dusche“.

## Bonus-Regeln

| Regel | Beispiele |
|---|---|
| **Wo?** Wort + **-da** (nach a, ı, o, u) / **-de** (nach e, i, ö, ü) = in / auf / an | *masa**da*** (auf dem Tisch), *oda**da*** (im Zimmer), *ev**de*** (zu Hause) |
| Nach **ç f h k p s ş t** wird daraus **-ta / -te** | *yatak**ta*** (im Bett), *dolap**ta*** (im Schrank), *park**ta*** (im Park) |
| **auf / unter / neben**: *masanın* (des Tisches) + *üstünde / altında / yanında* | *Kedi masanın üstünde.* = Die Katze ist auf dem Tisch. |
| ***var*** = es gibt · ***yok*** = es gibt nicht (steht am Satzende) | *Odada bir yatak var.* · *Evde televizyon yok.* |

Neue kleine Wörter: *oda* = das Zimmer · *mutfak* = die Küche · *banyo* = das Bad · *nerede?* = wo? · *kedi* = die Katze

## Video selbst neu erzeugen

Voraussetzungen: Python 3.10+, `ffmpeg` und die Cairo-Bibliothek (für die SVG-Bilder).
Die Technik liegt in [`../lernvideo/`](../lernvideo/): `engine.py` (Stimmen, Grafik, Rendern) und
`nouns.py` (Bausteine für Wortkarten-Videos). Hier stehen nur Inhalte, Bonus-Szenen und Bilder.

```bash
pip install -r requirements.txt          # im Hauptordner des Repositorys
cd evde-video
python make_video.py                      # erzeugt output/evde_einrichtung_deutsch_tuerkisch.mp4
python make_video.py --preview            # nur Standbilder nach build/preview/
pip install sherpa-onnx
python make_video.py --verify --takes 20  # Aussprache per Whisper prüfen, beste Aufnahme je Wort wählen
```
