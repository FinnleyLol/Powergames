## Mamas Seite – Papas Seite

Im Türkischen sagt das Wort gleich, zu welcher Seite der Familie jemand gehört:

| | Annenin tarafı (Mamas Seite) | Babanın tarafı (Papas Seite) |
|---|---|---|
| Oma | **anneanne** (wörtlich: Mutter-Mutter) | **babaanne** (wörtlich: Vater-Mutter) |
| Tante | **teyze** | **hala** |
| Onkel | **dayı** | **amca** |

*abla* (ältere Schwester), *abi* (älterer Bruder), *teyze* und *amca* sind außerdem höfliche Anreden:
Eine fremde ältere Frau sprichst du oft mit *teyze* an, einen älteren Mann mit *amca*.

| Deutsch | Türkisch | Aussprache | Tipp |
|---|---|---|---|
| die Tante (Mamas Schwester) | **teyze** | tei · se | auch: freundliche Anrede für ältere Frauen |
| die Tante (Papas Schwester) | **hala** | ha · la |  |
| der Onkel (Mamas Bruder) | **dayı** | da · jı | ı = dumpfes i |
| der Onkel (Papas Bruder) | **amca** | am · dscha | c = „dsch“ · auch Anrede für ältere Männer |
| der Cousin / die Cousine | **kuzen** | ku · **sen** | ein Wort für beide |

**Zur Betonung:** Bei den Verwandtschaftswörtern (*anne, baba, abla, teyze, hala, dayı, amca, aile, anneanne,
babaanne*) ist im Video **keine Silbe rot markiert**. Viele Sprecher betonen diese Wörter vorn (z. B. ***an**ne*,
***tey**ze*), die Computerstimme aber oft hinten. Hör am besten auf echte Sprecher.

**Aussprache-Check:** 53 von 59 türkischen Aufnahmen wurden von Whisper exakt erkannt. Unsicher bleibt
***oğul*** (Sohn): Kein Durchgang wurde exakt erkannt, auch nicht mit den beiden anderen türkischen
Computerstimmen. Die Erkennung rät dabei sehr unterschiedlich („oğuz“, „olay“ …), was eher auf die Erkennung
als auf die Stimme hindeutet. Richtig klingt es so: **o-ul**, das ğ ist stumm, das **l** am Ende deutlich.
Im Alltag hörst du fast immer *oğlum* (mein Sohn). Bei *kızım* hört die Erkennung manchmal „kızın“:
Achte auf das **m** am Ende.

## Bonus-Regeln

| Regel | Beispiele |
|---|---|
| **mein …** nach Vokal: nur **-m** | *anne**m*** (meine Mutter), *baba**m*** (mein Vater), *abla**m*** |
| **mein …** nach Konsonant: **-ım / -im / -um / -üm** | *kardeş**im***, *kız**ım***, *torun**um*** |
| Bei *oğul* fällt das u weg | *oğul* → *oğl**um*** (mein Sohn) |
| **dein …:** -(ı)n | *kardeş**in*** (dein Geschwister) · *Kaç kardeşin var?* = Wie viele Geschwister hast du? |
| „Ich habe …“ = **mein … var** | *İki kardeşim var.* = Ich habe zwei Geschwister. · *Kardeşim yok.* = Ich habe keine Geschwister. |

## Bilder

Twemoji hat für Familien nur blaue Piktogramme. Darum werden die Bilder zusammengesetzt:
*anne* = Frau + Mädchen, *baba* = Mann + Junge, *aile* = vier Gesichter. Verwandte von Mamas bzw. Papas Seite
haben ein kleines Abzeichen (👩 bzw. 👨) oben rechts.

## Video selbst neu erzeugen

Voraussetzungen: Python 3.10+, `ffmpeg` und die Cairo-Bibliothek (für die SVG-Bilder).
Die Technik liegt in [`../lernvideo/`](../lernvideo/): `engine.py` (Stimmen, Grafik, Rendern) und
`nouns.py` (Bausteine für Wortkarten-Videos). Hier stehen nur Inhalte und die Bonus-Szenen.

```bash
pip install -r requirements.txt          # im Hauptordner des Repositorys
cd aile-video
python make_video.py                      # erzeugt output/aile_familie_deutsch_tuerkisch.mp4
python make_video.py --preview            # nur Standbilder nach build/preview/
pip install sherpa-onnx
python make_video.py --verify --takes 20  # Aussprache per Whisper prüfen, beste Aufnahme je Wort wählen
```
