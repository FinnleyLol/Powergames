# Meslekler – Berufe auf Türkisch 🇩🇪 → 🇹🇷

Lernvideo (1080p, ca. 10 Minuten): 40 Berufe vom Arzt bis zur Journalistin, mit **türkischer Aussprache**. Dazu
kommen drei Bonus-Teile: **die Endung -cı** (*posta → postacı*), **„ich bin …“** (*öğretmenim, aşçıyım*) und
**Sätze über die Arbeit**.

Auf Türkisch gibt es für Mann und Frau **nur ein Wort**: *öğretmen* heißt Lehrer und Lehrerin, *doktor* Arzt und
Ärztin. In der Liste steht deshalb nur eine deutsche Form.

▶️ **Video:** [`output/meslekler_berufe_deutsch_tuerkisch.mp4`](output/meslekler_berufe_deutsch_tuerkisch.mp4)

Zu den 33 gewünschten Berufen sind sieben dazugekommen: Krankenpfleger, Verkäufer, Architekt, Programmierer,
Schneider, Schauspieler und Journalist.

Die betonte Silbe stammt aus der Lautschrift der Stimme, damit Hinweis und Ton zusammenpassen. Bei
zusammengesetzten Wörtern wird das **erste** Wort betont (o·to·**büs** scho·fö·rü). Bei *bilim insanı* ist keine
Silbe markiert, weil die Stimme *bilim* vorne betont, im Alltag hört man meist bi·**lim**.

## Bonus 1: Die Endung -cı

| Wort | + Endung | Beruf |
|---|---|---|
| posta (Post) | posta**cı** | der Postbote |
| fırın (Ofen) | fırın**cı** | der Bäcker |
| şarkı (Lied) | şarkı**cı** | der Sänger |
| gazete (Zeitung) | gazete**ci** | der Journalist |
| çöp (Müll) | çöp**çü** | der Müllmann |
| balık (Fisch) | balık**çı** | der Fischer |

Die Endung heißt *-cı / -ci / -cu / -cü*, je nach letztem Vokal (wie bei *-lık* im Küchen-Video). Nach harten
Lauten (**p, t, k, ç, ş, s, f, h**) wird aus dem c ein **ç**: *çöp → çöpçü, balık → balıkçı, sanat → sanatçı*.
Weitere Berufe mit dieser Endung im Video: *eczacı, itfaiyeci, taksici, elektrikçi, tamirci, temizlikçi, aşçı,
çiftçi, yazılımcı, oyuncu*.

## Bonus 2: Ich bin …

| Beruf | ich bin … |
|---|---|
| öğretmen | öğretmen**im** = ich bin Lehrer/in |
| doktor | doktor**um** = ich bin Arzt/Ärztin |
| polis | polis**im** = ich bin Polizist/in |
| mühendis | mühendis**im** = ich bin Ingenieur/in |
| şoför | şoför**üm** = ich bin Fahrer/in |
| aşçı | aşçı**yım** = ich bin Koch/Köchin |

Die Endung **-im / -ım / -um / -üm** heißt „ich bin“ und passt sich dem letzten Vokal an. Endet das Wort auf
einen Vokal, kommt ein **y** dazwischen (*aşçıyım, hemşireyim*). Das *ben* (ich) kann man weglassen:
*Öğretmenim.* = Ich bin Lehrer/in.

## Bonus 3: Bei der Arbeit

| Türkisch | Deutsch |
|---|---|
| Ne iş yapıyorsun? | Was machst du beruflich? |
| Ben hemşireyim. | Ich bin Krankenpfleger(in). |
| Nerede çalışıyorsun? | Wo arbeitest du? |
| Hastanede çalışıyorum. | Ich arbeite im Krankenhaus. |

*iş* = Arbeit, Job · *çalışmak* = arbeiten · *hastane* = Krankenhaus · *-de* = in (wie *evde* im
Einrichtungs-Video).

Zum Schluss: ***Kolay gelsin!*** sagt man in der Türkei zu allen, die gerade arbeiten, ungefähr „Frohes Schaffen!“.

## Video selbst neu erzeugen

Voraussetzungen: Python 3.10+, `ffmpeg` und die Cairo-Bibliothek (für die SVG-Bilder).
Die Technik liegt in [`../lernvideo/`](../lernvideo/): `engine.py` (Stimmen, Grafik, Rendern) und
`nouns.py` (Bausteine für Wortkarten-Videos). Hier stehen nur Inhalte und die Bonus-Tafeln.

```bash
pip install -r requirements.txt          # im Hauptordner des Repositorys
cd meslek-video
python make_video.py                      # erzeugt output/meslekler_berufe_deutsch_tuerkisch.mp4
python make_video.py --preview            # nur Standbilder nach build/preview/
pip install sherpa-onnx
python make_video.py --verify --takes 20  # Aussprache per Whisper prüfen, beste Aufnahme je Wort wählen
```
