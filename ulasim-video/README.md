## Bonus 1: Zusammengesetzte Wörter

Im Deutschen klebst du Wörter zusammen: Bus + Haltestelle = Bushaltestelle. Im Türkischen bleiben beide Wörter
getrennt, und das **zweite** bekommt eine kleine Endung:

| Wort 1 + Wort 2 | zusammen | Deutsch |
|---|---|---|
| otobüs + durak | otobüs dura**ğı** | die Bushaltestelle |
| tren + istasyon | tren istasyon**u** | der Bahnhof |
| trafik + ışık | trafik ışı**ğı** | die Ampel |
| polis + araba | polis araba**sı** | das Polizeiauto |
| kum + saat | kum saat**i** | die Sanduhr |

Die Endung ist **-ı / -i / -u / -ü** (nach Vokal **-sı / -si / -su / -sü**). Ein **k** am Ende wird zu **ğ**
(*durak → durağı*). Das kennst du schon aus anderen Videos: *ayak parmağı* (Zeh), *çamaşır makinesi* (Waschmaschine).

## Bonus 2: mit dem …

| Wort | mit … | Deutsch |
|---|---|---|
| otobüs | otobüs**le** | mit dem Bus |
| tren | tren**le** | mit dem Zug |
| uçak | uçak**la** | mit dem Flugzeug |
| araba | araba**yla** | mit dem Auto |
| taksi | taksi**yle** | mit dem Taxi |

**-le** nach e, i, ö, ü · **-la** nach a, ı, o, u. Endet das Wort auf einen Vokal, kommt ein **y** dazwischen.
Beispiel: *Otobüsle gidiyorum.* = Ich fahre mit dem Bus.

Neue kleine Wörter: *nerede* = wo · *ne kadar* = wie viel · *ne zaman* = wann · *lütfen* = bitte ·
*İyi yolculuklar!* = Gute Reise!

## Video selbst neu erzeugen

Voraussetzungen: Python 3.10+, `ffmpeg` und die Cairo-Bibliothek (für die SVG-Bilder).
Die Technik liegt in [`../lernvideo/`](../lernvideo/): `engine.py` (Stimmen, Grafik, Rendern) und
`nouns.py` (Bausteine für Wortkarten-Videos). Hier stehen nur Inhalte und die Bonus-Szenen.

```bash
pip install -r requirements.txt          # im Hauptordner des Repositorys
cd ulasim-video
python make_video.py                      # erzeugt output/ulasim_verkehrsmittel_deutsch_tuerkisch.mp4
python make_video.py --preview            # nur Standbilder nach build/preview/
pip install sherpa-onnx
python make_video.py --verify --takes 20  # Aussprache per Whisper prüfen, beste Aufnahme je Wort wählen
```
