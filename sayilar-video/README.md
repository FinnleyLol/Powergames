# Sayılar – Zahlen auf Türkisch 🇩🇪 → 🇹🇷

Lernvideo (1080p, ca. 8 Minuten): 30 Zahlwörter von **0 bis 20**, die **Zehner**, **hundert** und **tausend**, mit
**türkischer Aussprache**. Dazu kommen vier Bonus-Teile mit den Regeln für größere Zahlen: **Zehner + Einer**
(*yirmi beş*), **Hunderter und Tausender** (*iki yüz, beş bin*), **große Zahlen bauen** (*bin dört yüz elli üç*)
und **Zahlen im Alltag**.

▶️ **Video:** [`output/sayilar_zahlen_deutsch_tuerkisch.mp4`](output/sayilar_zahlen_deutsch_tuerkisch.mp4)

### 3. Onluklar, yüz ve bin – Zehner, hundert & tausend

| Zahl | Deutsch | Türkisch | Aussprache (betonte Silbe **fett**) | Tipp |
|---|---|---|---|---|
| 30 | dreißig | **otuz** | **o** · tus | Betonung vorne: O-tuz |
| 40 | vierzig | **kırk** | **kırk** | ı = dumpfes i |
| 50 | fünfzig | **elli** | el · **li** | doppeltes l deutlich sprechen |
| 60 | sechzig | **altmış** | alt · **mısch** | altı (6) → altmış (60) |
| 70 | siebzig | **yetmiş** | jet · **misch** | yedi (7) → yetmiş (70) |
| 80 | achtzig | **seksen** | **sek** · sen | sekiz (8) → seksen (80) |
| 90 | neunzig | **doksan** | **dok** · san | dokuz (9) → doksan (90) |
| 100 | hundert | **yüz** | **jüs** | nur yüz, ohne „bir“ · yüz heißt auch: Gesicht |
| 1.000 | tausend | **bin** | **bin** | nur bin, ohne „bir“ |
Die betonte Silbe stammt aus der Lautschrift der Stimme. Fast alle Zahlen werden hinten betont, aber
**se**·kiz (8), **do**·kuz (9), **o**·tuz (30), **sek**·sen (80) und **dok**·san (90) vorne. Bei 11–19 ist keine Silbe
markiert: Jedes Wort behält seine eigene Betonung (on · i·**ki**).

**Merkhilfe:** 60–90 ähneln 6–9: *altı → altmış*, *yedi → yetmiş*, *sekiz → seksen*, *dokuz → doksan*.
20–50 musst du lernen: *yirmi, otuz, kırk, elli*.

## Die Regeln für größere Zahlen

### 1. Zehner + Einer: erst der Zehner

| Zahl | Türkisch | wörtlich |
|---|---|---|
| 11 | on bir | zehn eins |
| 21 | yirmi bir | zwanzig eins |
| 25 | yirmi beş | zwanzig fünf |
| 34 | otuz dört | dreißig vier |
| 47 | kırk yedi | vierzig sieben |
| 58 | elli sekiz | fünfzig acht |
| 99 | doksan dokuz | neunzig neun |

Im Deutschen sagst du „fünf-und-zwanzig“ (5 + 20), auf Türkisch **yirmi beş** (20 + 5), ohne „und“.
So wie man die Zahl liest: von links nach rechts.

### 2. Hunderter und Tausender: die Zahl davor sagt „wie oft“

| Zahl | Türkisch | Hinweis |
|---|---|---|
| 100 | **yüz** | nicht „bir yüz“ |
| 200 / 300 | iki yüz / üç yüz | 2 × 100 / 3 × 100 |
| 1.000 | **bin** | nicht „bir bin“ |
| 5.000 | beş bin | 5 × 1.000 |
| 10.000 | on bin | 10 × 1.000 |
| 100.000 | yüz bin | 100 × 1.000 |
| 1.000.000 | **bir milyon** | hier mit *bir*! |

### 3. Große Zahlen bauen: von groß nach klein

| Zahl | Türkisch | Bausteine |
|---|---|---|
| 365 | üç yüz altmış beş | 300 + 60 + 5 |
| 999 | dokuz yüz doksan dokuz | 900 + 90 + 9 |
| 1453 | bin dört yüz elli üç | 1.000 + 400 + 50 + 3 |
| 2026 | iki bin yirmi altı | 2.000 + 20 + 6 |

Jahreszahlen sagst du ganz normal als Zahl: 1453 = *bin dört yüz elli üç* (tausend vierhundert…), nicht
„vierzehnhundert…“. (1453 ist das Jahr, in dem Konstantinopel zu İstanbul wurde.)

### 4. Zahlen im Alltag

| Türkisch | Deutsch |
|---|---|
| Kaç yaşındasın? | Wie alt bist du? |
| Yirmi beş yaşındayım. | Ich bin 25 Jahre alt. |
| Bu kaç lira? | Wie viel Lira kostet das? |
| Elli lira. | Fünfzig Lira. |

*kaç?* = wie viel(e)? · *yaş* = das Alter · Nach einer Zahl steht **keine Mehrzahl**: *iki elma* = zwei Äpfel
(nicht *iki elmalar*), *üç kedi* = drei Katzen.

## Video selbst neu erzeugen

Voraussetzungen: Python 3.10+, `ffmpeg` und die Cairo-Bibliothek (für die SVG-Bilder).
Die Technik liegt in [`../lernvideo/`](../lernvideo/): `engine.py` (Stimmen, Grafik, Rendern) und
`nouns.py` (Bausteine für Wortkarten-Videos). Hier stehen nur Inhalte, die Bonus-Tafeln und die Ziffern-Bilder
(`number_icon`, im Code gezeichnet, bei 1–10 mit Zählpunkten).

```bash
pip install -r requirements.txt          # im Hauptordner des Repositorys
cd sayilar-video
python make_video.py                      # erzeugt output/sayilar_zahlen_deutsch_tuerkisch.mp4
python make_video.py --preview            # nur Standbilder nach build/preview/
pip install sherpa-onnx
python make_video.py --verify --takes 20  # Aussprache per Whisper prüfen, beste Aufnahme je Wort wählen
```
